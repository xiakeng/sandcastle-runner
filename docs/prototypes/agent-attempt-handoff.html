Agent Attempt handoff

This prototype tests when a Sandcastle-run Codex attempt may hand a local worktree back to the runner.

Prompt shape

The runner fills this Markdown template after it creates the worktree and updates its main base.

# TASK

Implement Delivery Ticket {{TICKET_NUMBER}}: {{TICKET_TITLE}}

Use [$implement]({{IMPLEMENT_SKILL_PATH}}). Only work on this Delivery Ticket.

# WORKTREE

- Path: {{WORKTREE_PATH}}
- Branch: {{BRANCH}}
- Fresh main commit: {{BASE_SHA}}

The runner already created this worktree from the latest main commit. Work only in this path.

# DELIVERY BOUNDARY

Run the appropriate checks and commit local changes. Do not push, create or update a pull request,
merge, close the ticket, or modify tracker state. The runner owns those operations.

# RESULT

End with exactly one <agent_attempt_result> tag containing JSON with this shape:

{
  "outcome": "committed | no_change | blocked",
  "summary": "what happened and why",
  "commits": [{ "sha": "claimed commit SHA", "message": "subject" }],
  "checks": [{ "command": "command", "status": "passed | failed | not_run", "details": "result" }],
  "blocker": "required when outcome is blocked; otherwise null"
}

Explain no_change or blocked fully. The runner independently verifies Git state and commits.
